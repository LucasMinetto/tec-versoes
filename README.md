# TEC — versões

APKs do aplicativo TEC para a equipe. O aplicativo consulta `versao.json` uma vez por dia e oferece a atualização.

Publicado por `android/publicar-versao.ps1` (repositório privado do app).

## iPhone

O TEC no iPhone é instalado pelo Safari, sem arquivo para baixar e sem App Store. Veja o passo a passo em [INSTALAR-IPHONE.md](INSTALAR-IPHONE.md).
